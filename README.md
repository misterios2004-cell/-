# Лисьи норы

Пошаговая 3D-тактика про отряды антропоморфных лис-солдат. Механика (звания, инвентарь, техника, ход с таймером) вдохновлена Hogs of War (Infogrames, 2000); проект с правообладателями не связан.

Игра работает в браузере (в том числе в Safari на iPhone) и собирается в приложения для Android (APK) и iOS (IPA).

## Как установить на Android

1. Откройте вкладку **Releases** (или **Actions → Android APK** → последний запуск → артефакт `lisi-nory-apk`).
2. Скачайте `lisi-nory.apk` на телефон и откройте файл.
3. Разрешите установку из этого источника, когда Android спросит.

APK собирается автоматически GitHub Actions при каждом изменении игры (`.github/workflows/android.yml`). Это отладочная сборка: её можно ставить напрямую, но для Google Play нужна подписанная release-сборка.

## Как установить на iPhone

**Способ 1 — через Safari (без компьютера и аккаунта разработчика).**
1. Один раз включите публикацию: *Settings → Pages → Build and deployment → Source: Deploy from a branch → `gh-pages` / (root) → Save*. Ветку `gh-pages` создаёт workflow `.github/workflows/pages.yml`.
2. Откройте на айфоне в Safari https://misterios2004-cell.github.io/-/
3. Нажмите «Поделиться» → «На экран Домой». Игра откроется на весь экран со своей иконкой и после первого запуска работает без интернета.

**Способ 2 — настоящее iOS-приложение (.ipa).** GitHub Actions собирает `lisi-nory.ipa` (`.github/workflows/ios.yml`) и кладёт его в Releases. Файл без подписи Apple: установите его через [Sideloadly](https://sideloadly.io) или [AltStore](https://altstore.io) с компьютера (Windows или Mac) под своим Apple ID. С бесплатным Apple ID приложение нужно переподписывать раз в 7 дней; с платным аккаунтом разработчика ($99 в год) — раз в год, также открывается TestFlight и App Store.

## Как запустить в браузере

```bash
npm run serve        # или: python3 -m http.server 8080 --directory www
```

Откройте http://localhost:8080. Онлайн-версия публикуется в GitHub Pages (см. раздел про iPhone).

## Что есть в игре

**Кампания** — 13 операций в пяти регионах (поля, топи, северный перевал, пустыня, финальный остров). Задачи: уничтожить противника, убить коменданта, дойти до флага, продержаться N раундов. Прогресс сохраняется на устройстве.

**Звания и повышения** — как в оригинале: все начинают рядовыми (50 HP), дальше четыре ветки по три ступени:

| Ветка | 1 | 2 | 3 |
|---|---|---|---|
| Тяжёлое вооружение | Стрелок, 75 | Бомбардир, 90 | Пиротехник, 120 |
| Инженеры | Сапёр, 80 | Инженер, 100 | Диверсант, 120 |
| Разведка | Разведчик, 75 | Снайпер, 90 | Шпион, 120 |
| Медслужба | Санитар, 60 | Медик, 80 | Хирург, 120 |

После третьей ступени — Коммандо (130), затем Герой (150). В финале ждут Легенды (200). Очки повышения: +1 за операцию, +1 если все выжили, +1 за каждую найденную медаль, +2 за освобождённый регион.

**Инвентарь** — у каждого звания свой набор: 32 вида оружия и снаряжения. Ближний бой (нож, кастет, сабля, электрошокер), стрелковое (пистолет, винтовка, очередь, снайперка с оптикой, транквилизатор, пулемёты, дробовики), тяжёлое (базука, миномёт, шрапнельный залп, огненный дождь, огнемёт), взрывчатка (гранаты: обычная, осколочная, кассетная, газовая; мины, динамит, самоподрыв), авиаудар, ударная волна, медицина (лечащие руки, дротик, лечебный шар, самолечение), реактивный ранец, маскировка, карманная кража.

**Техника** — танк, дот и гаубица: в них можно сесть, они защищают экипаж, пока целы.

**Мир** — разрушаемый рельеф, дома, мешки с песком, изгороди, колючая проволока, мосты, мельницы, взрывающиеся бочки, мины. Бойцы ходят, бегают (тратится выносливость), прыгают, идут вброд и плавают; зелёная вода отравляет. Дирижабли сбрасывают ящики с оружием и аптечками.

**Схватка** — 2–4 армии, игроки и ИИ трёх уровней в любом сочетании, выбор местности, рельефа, званий, техники, ветра.

## Персонажи и стиль

- **Лисы-солдаты** — двуногий скелет (`BipedalFox` в `www/js/models.js`): таз → позвоночник → шея → голова; плечо → локоть → кисть; бедро → колено → ботинок; хвост из пяти сегментов.
- **Столкновения** — вертикальная капсула `FOX_BODY` (рост 1,82 м, радиус 0,34 м). По ней считаются попадания пуль и снарядов, урон от взрыва, проходы между постройками.
- **Анимации** — конечный автомат `FoxAnim` (idle, walk, run, air, swim, aim, dead, celebrate, sleep) с плавными переходами и одноразовые действия `FoxAction` (attack, throw, fire, hit, place), накладываемые поверх.
- **Вода** — вброд до глубины 1,15 м, глубже боец плывёт.
- **Стиль** — `www/js/theme.js`: токены интерфейса и шрифты (`UI_THEME`), PBR-предустановки материалов (`MATERIALS`), палитра меха (`FOX_PALETTE`), цвета эффектов (`VFX`). Материалы — `MeshStandardMaterial` с картами нормалей, тональная компрессия ACES; на низком качестве графики — упрощённые материалы.
- Сохранения прошлой версии переносятся автоматически. Идентификатор приложения `com.svinyi.okopy` оставлен прежним, чтобы установленное приложение обновилось, а не встало второй копией.

## Устройство проекта

- `www/` — игра (HTML, CSS, JavaScript-модули, без сборщика)
  - `js/theme.js` — визуальный стиль: интерфейс, шрифты, материалы, эффекты
  - `js/data.js` — фракции, звания, оружие, миссии
  - `js/battle.js` — ходы, физика бойцов (капсула), оружие, техника, камера
  - `js/ai.js` — искусственный интеллект
  - `js/world.js` — рельеф, вода, постройки, столкновения
  - `js/models.js` — процедурные 3D-модели, скелет и аниматор лис
  - `js/ui.js` — меню, кампания, казарма, HUD, управление
  - `vendor/` — Three.js r128 и Capacitor core (MIT)
- `resources/` — иконки и заставки для Android и iOS
- `capacitor.config.json`, `package.json` — нативная оболочка Android и iOS (Capacitor 6)
- `.github/workflows/` — сборка APK, IPA и публикация веб-версии
