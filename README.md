# Свиньи в окопах

Пошаговая артиллерийская игра в духе Hogs of War: два отряда свиней воюют на разрушаемой местности.

Откройте `index.html` в браузере — установка не нужна.

- Режимы: против компьютера (3 уровня меткости) или вдвоём за одним экраном
- Оружие: базука (сносит ветром), граната (отскакивает, взрыв через 3 с), дробовик, авиаудар (1 раз за игру)
- Разрушаемый ландшафт, ветер, урон от падения, вода по краям острова
- Управление: мышь/палец — прицел, зажать и отпустить — выстрел; ←/→ ходьба, ↑/↓ угол, Пробел — огонь, Enter — прыжок, 1–4 — оружие
