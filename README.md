# Система обучения и аттестации персонала

Настольное приложение для службы по ремонту медицинского оборудования. Реализует документ
«Система обучения, уровней и аттестации персонала» (единая шкала У0—У5): учебные материалы,
тренировку по банку вопросов, проведение аттестации, проверку комиссией и печать протоколов.

## Возможности

**Сотрудник / ученик**
- «Мой путь» — текущий уровень, условия перехода на следующий (раздел 4.1), критерии У0 → У1 и
  У1 → У2, разрывы в матрице компетенций, журнал опросов, история тренировок.
- Учебные материалы — Часть I документа (блоки 0—4), порядок аттестации, практические задания;
  оглавление и поиск.
- Тест по темам — 48 закрытых вопросов Модуля 1 с мгновенной проверкой, режим «только ошибки».
- Открытые вопросы — 62 вопроса (отсос, классификация, опросники У2 → У3 … У4 → У5) с эталонами и
  самооценкой 0 / 1 / 2.
- Пробная аттестация — билет по правилам раздела 5 с таймером и разбором.

**Комиссия / наставник** (вход по паролю, задаётся при первом запуске)
- Карточка сотрудника: уровень, допуски, матрица компетенций H1—H12, S1—S8, журнал опросов по
  выполненным работам (раздел 2.3), блокирующие факторы, отметки по критериям перехода.
- Официальная аттестация: билет формируется автоматически (У0 → У1: 20 закрытых + 8 открытых;
  У1 → У2: 30 закрытых + 10 открытых, обязательно № 3, 5, 14; У2 → У3 … У4 → У5: 10 открытых),
  закрытая часть — 45 минут, открытая — 60 минут, варианты ответов перемешиваются.
- Проверка: закрытая часть считается автоматически; открытую часть, защиту трёх работ, практическое
  задание и документацию оценивает комиссия. Порог — 80 % по каждой части, «0» по блокирующему
  вопросу — несдача части.
- Протокол с бланком ответов и карта уровня сотрудника — в HTML для печати. При утверждении
  протокола с решением «присвоить» уровень сотрудника обновляется.

## Запуск

Готовый файл для Windows: вкладка **Actions** репозитория → последняя успешная сборка → артефакт
`Attestation-windows` (внутри `Attestation.exe`, установка не требуется).

Из исходников (Python 3.10+ с Tkinter, сторонние пакеты не нужны):

```
python run.py
```

Данные хранятся в `%APPDATA%\AttestationMedRepair\attestation.db` (Windows) или
`~/.local/share/AttestationMedRepair/attestation.db`. Другой путь (например, общий сетевой файл)
задаётся переменной окружения `ATTESTATION_DB`. Резервная копия — «Настройки → Сделать резервную копию».

## Обновление банка вопросов

Вопросы и материалы извлекаются из исходного .docx автоматически, а не переписываются вручную:

```
pip install python-docx
python tools/extract_docx.py "путь/к/документу.docx"
```

Скрипт перезаписывает `attestation/data/bank.json` и `attestation/data/materials.json`. Структура
документа (таблицы вопросов «№ / Вопрос и варианты ответа / Ключ» и «№ / Вопрос / Эталонный ответ»)
должна сохраняться.
