# Свиньи в окопах 3D

Пошаговая артиллерийская игра в духе Hogs of War: отряды свиней воюют на трёхмерной разрушаемой местности.

## Как запустить

- **Локально:** запустите любой статический сервер в папке проекта, например `python3 -m http.server`, и откройте `http://localhost:8000`.
- **Как приложение (PWA):** опубликуйте репозиторий через GitHub Pages (Settings → Pages → ветка). Откройте сайт в Chrome на Android или ПК и выберите «Установить приложение» / «Добавить на главный экран». В Safari на iPhone: «Поделиться» → «На экран Домой». После первого запуска игра работает без интернета.

## Что есть

- Кампания из 6 уровней: учебный плацдарм, окопы, минное поле, остров при сильном ветре, ночной бой в тумане, финал с генералом (200 HP). Прогресс и звёзды сохраняются на устройстве.
- Схватка на случайной карте: против компьютера (3 уровня меткости) или вдвоём за одним экраном.
- Оружие: базука (сносит ветром), граната (отскакивает, взрыв через 3 с), дробовик, авиаудар.
- Разрушаемый рельеф, взрывающиеся бочки, мины, вода, урон от падения.
- Управление с клавиатуры, мышью и сенсорными кнопками.

`classic.html` — первая, двухмерная версия игры.

## Управление

| Клавиша | Действие |
|---|---|
| W / S | вперёд / назад |
| A / D, ← / → | поворот |
| ↑ / ↓ или перетаскивание по экрану | угол ствола |
| Пробел (зажать и отпустить) | выстрел |
| Enter | прыжок |
| 1–4 | оружие |
| C | обзор карты |
| Esc | пауза |
