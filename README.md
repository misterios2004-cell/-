# Свиньи в окопах

Пошаговая 3D-стратегия про свиные армии по мотивам Hogs of War (Infogrames, 2000). Фанатский проект, с правообладателями не связан.

Игра работает в браузере и собирается в Android-приложение (APK).

## Как установить на Android

1. Откройте вкладку **Releases** (или **Actions → Android APK** → последний запуск → артефакт `svinyi-v-okopah-apk`).
2. Скачайте `svinyi-v-okopah.apk` на телефон и откройте файл.
3. Разрешите установку из этого источника, когда Android спросит.

APK собирается автоматически GitHub Actions при каждом изменении игры (`.github/workflows/android.yml`). Это отладочная сборка: её можно ставить напрямую, но для Google Play нужна подписанная release-сборка.

## Как запустить в браузере

```bash
npm run serve        # или: python3 -m http.server 8080 --directory www
```

Откройте http://localhost:8080. Для веб-версии с установкой «на главный экран» включите GitHub Pages: *Settings → Pages → Source: GitHub Actions*, после чего `.github/workflows/pages.yml` публикует папку `www` при пуше в `main`.

## Что есть в игре

**Кампания** — 13 операций в пяти регионах (ферма, болота, зима, пустыня, финальный остров). Задачи: уничтожить противника, убить коменданта, дойти до флага, продержаться N раундов. Прогресс сохраняется на устройстве.

**Звания и повышения** — как в оригинале: все начинают рядовыми (50 HP), дальше четыре ветки по три ступени:

| Ветка | 1 | 2 | 3 |
|---|---|---|---|
| Тяжёлое вооружение | Стрелок, 75 | Бомбардир, 90 | Пиротехник, 120 |
| Инженеры | Сапёр, 80 | Инженер, 100 | Диверсант, 120 |
| Разведка | Разведчик, 75 | Снайпер, 90 | Шпион, 120 |
| Медслужба | Санитар, 60 | Медик, 80 | Хирург, 120 |

После третьей ступени — Коммандо (130), затем Герой (150). В финале ждут Легенды (200). Очки повышения: +1 за операцию, +1 если все выжили, +1 за каждую найденную медаль, +2 за освобождённый регион.

**Инвентарь** — у каждого звания свой набор: 32 вида оружия и снаряжения. Ближний бой (нож, копыто, сабля, электрошокер), стрелковое (пистолет, винтовка, очередь, снайперка с оптикой, транквилизатор, пулемёты, дробовики), тяжёлое (базука, миномёт, шрапнельный залп, огненный дождь, огнемёт), взрывчатка (гранаты: обычная, осколочная, кассетная, газовая; мины, динамит, самоподрыв), авиаудар, ударная волна, медицина (лечащие руки, дротик, лечебный шар, самолечение), реактивный ранец, маскировка, карманная кража.

**Техника** — танк, дот и гаубица: в них можно сесть, они защищают экипаж, пока целы.

**Мир** — разрушаемый рельеф, дома, мешки с песком, изгороди, колючая проволока, мосты, мельницы, взрывающиеся бочки, мины. Свиньи ходят, бегают (тратится выносливость), прыгают и плавают; зелёная вода отравляет. Дирижабли сбрасывают ящики с оружием и аптечками.

**Схватка** — 2–4 армии, игроки и ИИ трёх уровней в любом сочетании, выбор местности, рельефа, званий, техники, ветра.

## Управление

| Клавиатура | Сенсорный экран | Действие |
|---|---|---|
| W / S | джойстик вверх/вниз | вперёд / назад |
| A / D, ← / → | джойстик влево/вправо | поворот |
| ↑ / ↓, колесо, перетаскивание мышью | провести пальцем по полю, ▲ ▼ | наводка |
| Shift | «Бег» | бег |
| Пробел (зажать) | «Огонь» (зажать) | выстрел, сила броска |
| Enter | «Прыжок» | прыжок, полёт на ранце |
| Tab / I, 1–9 | кнопка оружия | инвентарь |
| F | «Сесть» / «Выйти» | техника |
| V | «Прицел» | оптический прицел |
| C | ◎ | обзор карты |
| Backspace | «Пропустить ход» | пропуск хода |
| Esc | ❚❚ / «Назад» | пауза |

## Устройство проекта

- `www/` — игра (HTML, CSS, JavaScript-модули, без сборщика)
  - `js/data.js` — нации, звания, оружие, миссии
  - `js/battle.js` — ходы, физика свиней, оружие, техника, камера
  - `js/ai.js` — искусственный интеллект
  - `js/world.js` — рельеф, вода, постройки, столкновения
  - `js/models.js` — процедурные 3D-модели
  - `js/ui.js` — меню, кампания, казарма, HUD, управление
  - `vendor/` — Three.js r128 и Capacitor core (MIT)
- `resources/` — иконки и заставка Android
- `capacitor.config.json`, `package.json` — оболочка Android (Capacitor 6)
